# NeonFX

Omarchy theme: void purple background, **cyan default text** (`#00f5ff`), magenta/pink accents, Ghostty GPU shaders.

## Before editing

1. Edit files in the **repo** (`~/projects/NeonFX` or clone path), not only `~/.config/omarchy/themes/neonfx` — the theme dir should be a symlink to the repo during development.
2. After color or config changes, re-apply wiring and open a **new shell tab**:

```bash
bash ~/.config/omarchy/hooks/theme-set.d/neonfx.sh neonfx
# or: ./install --skip-apply && omarchy theme set "NeonFX"
```

3. Run `neonfx-doctor` to verify symlinks and env.

## Source-of-truth files

| Change | Edit | Also sync |
|--------|------|-----------|
| Terminal palette | `colors.toml` | `ghostty.conf` (foreground + `palette = N=`) |
| Fish prompt/syntax | `fish.conf` | copied by `hooks/theme-set` → `~/.config/fish/conf.d/omarchy-theme.fish` |
| Bash + shared CLI env | `bash.conf`, `cli.env.sh` | hook generates fish `set --global` from `cli.env.sh` |
| bat syntax | `bat/NeonFX.tmTheme` | `bat cache --build` after edits |
| git colors | `git.conf` | hook symlinks to `~/.config/git/neonfx.gitconfig` |
| git diff pager | `delta.gitconfig` | only when `delta` installed |
| Prompt | `starship.toml` | symlinked to `~/.config/starship.toml` |
| TUI git | `lazygit/config.yml` | symlinked |
| eza / fzf / jq | `cli.env.sh` | bash sources it; fish dest is generated by the hook |
| Desktop UI | `waybar.css`, `walker.css`, `hyprland.conf`, … | Omarchy theme apply |
| MC skin | `mc.ini` | `~/.local/share/mc/skins/neonfx.ini` |
| Shaders | `shaders/*.glsl`, trail styles in `shaders/trails/` | `omarchy-neonfx-apply` after edits |

## Changing colors

**Palette reference:** [palette.md](palette.md)

Rules learned from this project:

- **`colors.toml` + `ghostty.conf` must match** for foreground and palette slots 0–15.
- **Avoid one color everywhere.** If default text is `#00f5ff`, shift overlapping roles:
  - Fish keywords/escape → `#66faff`
  - Fish cwd → `#33ffb8` (mint)
  - bat keys/tags → `#66faff`; strings stay `#ffb3e6` for contrast
  - eza dirs → `#66faff`, regular files → `#00f5ff`
  - starship paths → `bright_cyan` (`#66faff`), not same as `foreground`
- **Desktop vs terminal:** waybar/walker/btop use `#ece6ff`; terminal default is `#00f5ff`. Intentional — don't blindly unify without user request.
- **Accent colors stay neon** unless user asks to change the whole palette: magenta `#ff0099`, pink `#ff33aa`, mint `#33ffb8`, muted `#5a3a88` / `#7a6a98`.

## Install / uninstall / verify

```bash
./install                          # full setup + omarchy theme set
./install --skip-apply             # wire hooks only
neonfx-doctor             # check symlinks, git include, bat, env
neonfx-uninstall --switch-to "Tokyo Night"
```

Development symlink:

```bash
ln -sfn ~/projects/NeonFX ~/.config/omarchy/themes/neonfx
```

Hook entry point: `hooks/theme-set.d/neonfx.sh` — installs bat/MC/bash/git/starship/lazygit/fastfetch symlinks, gitconfig includes, Neon FX defaults.

## Neon FX (Ghostty only)

- Toggle state: `~/.local/state/omarchy/toggles/neonfx/`
- Generated overlay: `~/.local/state/omarchy/neonfx/ghostty-shaders.conf`
- Menu: `Super+Alt+Space` → Style → Neon FX (`extensions/menu.sh`)
- CLI: `omarchy-neonfx-toggle preset-full|preset-terminal|preset-off`
- After shader edits: `omarchy-neonfx-apply`, restart Ghostty

Alacritty gets palette only — no shader stack.

## Common fixes

| Symptom | Fix |
|---------|-----|
| Changes not visible | Re-run theme hook; new shell tab; Ghostty reload for palette |
| bat yellow/generic | `bat cache --build`; check `BAT_THEME='NeonFX'` in fish/bash |
| git uncolored | Re-run hook; verify `~/.gitconfig` includes neonfx.gitconfig |
| MC skin missing | Skin must live in `~/.local/share/mc/skins/`, not `~/.config/mc/skins/` |
| ANSI escapes print literally | Use `\033[38;2;%d;%d;%dm` not `%dm` in printf color helpers |

## Scope boundaries

- **In scope:** this repo's theme files, hooks, bin scripts, shaders, Omarchy theme integration.
- **Out of scope:** Omarchy source development in `~/.local/share/omarchy/` unless user explicitly asks.
- **Menu extension:** duplicates upstream Omarchy `show_style_menu` — diff against Omarchy when updating.
